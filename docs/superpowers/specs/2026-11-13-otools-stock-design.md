# OTools 股票工作台 v0.1.0

日期：2026-11-13。用户授权：按推荐方案直接实现；以 A 股为主，兼顾港股、美股。

## 目标与边界

新建可独立构建/打包的 `otools-stock`，中文名「股票工作台」，默认 `openMode: "panel"`。
提供真实第三方行情、自选分组、分时及日/周/月 K 线、价位/涨跌幅提醒、持股记账、导入导出。
不是券商客户端，不登录交易账户，不下单，不提供投资建议。仅本地保存私人持仓数据，不上传持仓。
直接使用当前 main；不创建分支/worktree，不改宿主或其他插件，不自动 commit、push、注册远程仓库或发布市场。

## 方案与技术选择

用户选择让实现者采用推荐方案。实现者选择 Vue 3 + TypeScript + Vite，与已有 panel 插件一致。
考虑：① 内嵌第三方股票网页，功能不可控且持仓隐私/嵌入策略难保证；② 新建 native 行情进程，
需要跨平台二进制但当前宿主已有 HTTP 能力；③ 原生前端 + 宿主 HTTP 桥 + 本地记账（采用）。
第三种保持独立 .oplg，无原生库和密钥；以随插件保存的官方 SDK 快照接入宿主。

## 行情

- 腾讯公开行情适配器。provider 单独封装，失败不会换成随机/示例价格。
- A 股使用 sh/sz/bj 六位代码，港股 hk 五位，美股 us 字母代码；非法代码不可形成远程 URL。大陆 B 股与特殊币种交易柜台暂不支持。
- 搜索：常用股票本地目录 + 代码直达 + 在线名字/拼音；在线失败提示，不执行返回的 JavaScript。
- 批量自选/持仓/提醒/大盘指数行情：成交价、昨收、开高低、量额、涨跌幅、换手率、PE、总市值、可用五档。
- 正确解码 GB18030/UTF-8；A 股成交量“手”转换为股，成交额转换为币种原单位。
- 分时及前复权日/周/月 K 线，仅展示服务器实际返回数据，稀疏/缺失/错误均明确提示。
- 展示交易所原始时间、请求时间、来源和可能延时；缓存/失效/请求失败不标记为实时。
- 默认 15 秒刷新，支持 5/10/15/30/60 秒、暂停/手动、隐藏节能、失败退避；请求不重叠，切换图表取消旧请求。
- 浏览器开发/本地预览使用仅绑定 127.0.0.1 的固定目标代理；安装到 OTools 使用 `otools_host_http_send`。

## 自选

默认提供少量常用股票但没有预置行情和持仓。自选支持添加/删除、置顶、分组增删改、组内上下移动、
股票名称/代码筛选、按价格/涨跌幅/成交额排序。删除自选不删除持仓/提醒和交易记录。

## 持股

- 开仓存量、买入、卖出三种记录；代码、交易日、数量（最多四位小数）、成交价（最多六位小数）、费用、备注。
- 存量记录表示该日开盘前已有持仓，每个证券最多一笔，且必须在买卖之前；其成本包括已录入费用。
- 加权平均成本，买入费用入成本，卖出费用扣收入；卖出数量超过当时持股拒绝。
- 使用整数定点/BigInt 中间值计算成本分摊；全部卖出释放全部剩余成本，不残留舍入成本。
- 展示持股数量、平均成本、市值、未实现盈亏/比率、已实现盈亏和行情交易日盈亏。
- 行情日盈亏 = 当前市值 - 昨收 × 隔夜数量 - 当日买入支出 + 当日卖出净收入；当日数量包含完整当日交易。
- 按 CNY/HKD/USD 分开汇总，绝不直接混加币种。不擅自填充汇率。
- 没有行情时市值/浮盈为未知，不以成本价伪造。部分缺价的币种汇总明确标为已知小计，并给出缺价数。
- 可编辑/删除交易，重新验证完整账本；导致历史超卖的编辑原子拒绝。

## 提醒

价格 >= / <=、涨跌幅 >= / <=；开关、冷却时间、跨阈值再武装、触发日志（最多 200 条）。
只处理新鲜、非未来、未重复的交易所时间：A 股上限 5 分钟，港/美股上限 30 分钟（可能延时）。
冷却期内再次跨阈值不消费武装，冷却期过后仍可触发。条件持续满足不循环刷屏。
默认站内提醒；声音/系统通知需用户主动启用并获得浏览器权限，失败明确提示。
页面关闭或暂停刷新后不承诺后台监控；无服务器提醒。

## 存储与备份

宿主 `getPluginLocalState/savePluginLocalState` 优先，无宿主时 localStorage。
版本化快照：instruments、groups、watchlist、trades、alerts、alertEvents、settings、quoteCache。
保存串行并对失败给出未保存提示；读取损坏/失败不覆盖原始记录，允许用户确认导入恢复。
JSON 完整备份/恢复：有效快照与导入均有 2 MiB 上限、各列表数目限制、有限数/日期/代码/ID/引用校验、账本超卖校验；
不合法备份整体拒绝，确认合法备份后才覆盖。导出自选/持仓 CSV（UTF-8 BOM，防 Excel 公式注入）。
宿主文件对话框/读写接口优先，浏览器 file input / Blob 下载兜底。

## 界面与可访问性

深色证券工作台默认主题，另支持浅色/跟随系统、红涨绿跌/绿涨红跌。主导航：自选盯盘、我的持仓、
价格提醒、设置与备份；顶部指数快照、全局搜索/刷新；自选列表和选中股票详情/图表。
宽 panel 双栏、窄 panel 可滚动并堆叠；文字/图标一并表达涨跌和状态，不只依靠颜色。
对话框有标签、Escape 和焦点管理；键盘搜索快捷键，交互按钮有可访问名称。
